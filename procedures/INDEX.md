# procedures · 索引

> **这不是卡片目录。** 卡名就是索引（`分类-现象`），检索靠**文件名 + 卡内 `> **触发**：` 那一整行现象词**。
> **新卡不必在这里登记** —— 加一张卡只改文件名，不用回来改这张表。

## 分类前缀

按**实际会撞上的场景**划，不按学科划：

```
部署-   插件/mod 的编译与部署、备份与移除
补丁-   Harmony 补丁挂不上/静默失效
编译-   改第三方本体源码（Fika 等）的编译链
数据-   游戏数据库、存档、日志的读取与判定
环境-   网络、Shell、工具链、机器迁移
发布-   把 mod 发到 GitHub / Gitee
诊断-   现象定不了根因时的排查手法
性能-   帧时间/内存的定位与优化
```

## 只写「卡名分不出来」的那几对

| 现象 | 读哪张 |
| --- | --- |
| 插件宣称移除了，实际还在跑 | `部署-备份放错位置等于没移除` |
| 补丁代码没报错，但功能毫无变化 | `补丁-TypeByName静默失败` |
| 补丁**报**了 IL Compile Error | `补丁-Harmony打不了readonly struct` |
| **403**，想知道是站点拒的还是本地代理拦的 | `诊断-区分403是谁返回的` |
| 连不上 / HTTP **000**，但同 URL PowerShell 能通 | `环境-curl和HttpWebRequest不走本地加速器` |
| 换机器后 agent 不读索引、不查经验卡 | `环境-换机器时全局钩子不跟着走` |
| 用 profiler 的 CSV 找"哪个 mod 慢"，得出一堆 mod 占大头 | `诊断-profiler的归属会误导` |
| 静态扫 IL 找"每帧危险调用"，得出一堆 mod 风险高 | `诊断-静态扫描必须核守卫` |
| 动态地图类 mod 进图卡 / 加载慢 / 内存涨 | `性能-SVG地图的三角化开销` |
| 想改 **Fika 本体**（加同步修复/看门狗），一编译几十个错 | `编译-Fika改源码` |
| 改完 dll 覆盖不进去：`user-mapped section open` | `编译-Fika改源码` |
| 移植 Fika 3.x（IL2CPP）代码到 4.x（Mono），方法签名对不上 | `编译-Fika改源码` §「EFT 4.1.6 差异」 |

> 其余一概不加 —— 现象词归卡名与卡内「触发」行。
> 索引一旦开始逐卡登记，就会随卡数线性增长，还会跟卡里的触发行变成两份真相。

## ★ 性能分析的三条纪律（今天各踩了一次）

```
① CSV 回答「哪条路径贵」，不回答「谁写的这段代码」
   ⇒ 必须反编译目标类型核对归属
② 静态扫描回答「有哪些风险点」，不回答「会不会执行」
   ⇒ 必须读方法开头的守卫
③ 两者都对一半，合起来才完整
   CSV 定位路径 → 反编译看归属 → 静态扫描核守卫
```
