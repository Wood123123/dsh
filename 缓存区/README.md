# 缓存区

> **这里放「只读」的东西** —— 参考源码、备份、素材包、日志、工具脚本。
> **不要在这里改代码**；需要改就去 `..\工作区\` 另建项目。
> 上级索引：`..\_索引.md`

## 五个分区

| 分区 | 内容 | 什么时候用 |
|---|---|---|
| `参考源码\` | 第三方 mod 的反编译源码 + 上游 GitHub 源码 + 官方 wiki | **查实现**时读（最重要的分区） |
| `备份\` | 配置/数据/插件的备份（带时间戳） | 回滚时用 |
| `素材包\` | 下载的 zip/7z、发行包、大体积工程 | 找原始包时用（平时不用读） |
| `日志与数据\` | 日志归档、测试数据集 | 排查历史问题时用 |
| `工具脚本\` | 顶层 .ps1 脚本 | 复用工具时用 |

## 注意

- `参考源码\` 里的东西**只读**，改了就没法作为参考基准了
- `素材包\` 占了绝大部分体积（约 550 MB），**不要往里读文件**，除非确实需要
- `备份\` 里的 `.bak_*` 文件名带时间戳，不要改名
